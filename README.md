# 青龙面板签到脚本集

青龙面板自用脚本，在 v2.23.0 正式版上实测。所有脚本共用 `ql_common.py`，公共逻辑只维护一份。

## 脚本清单

**签到脚本**

| 脚本                       | 任务名            | 时间  |
| -------------------------- | ----------------- | ----- |
| `aliyunpan_checkin.py`     | 阿里云盘签到      | 00:00 |
| `quark_checkin.py`         | 夸克网盘签到      | 00:00 |
| `ty_netdisk_checkin.py`    | 天翼云盘签到      | 00:00 |
| `enshan_checkin.py`        | 恩山论坛签到      | 00:00 |
| `smzdm_checkin.py`         | 什么值得买签到    | 00:00 |
| `workbuddy_checkin.py`     | WorkBuddy每日签到 | 00:00 |
| `netease_music_checkin.py` | 网易云音乐签到    | 00:00 |

**活动脚本**

| 脚本                             | 任务名            | 时间  |
| -------------------------------- | ----------------- | ----- |
| `smzdm_tasks.py`                 | 什么值得买活动    | 00:10 |
| `workbuddy_buddytravel_tasks.py` | WorkBuddy宠物探险 | 00:10 |

- 签到脚本统一使用 `0 0 * * *`，活动脚本统一使用 `10 0 * * *`。
- 活动脚本与对应签到脚本共用同一变量（`smzdm_*` 用 `SMZDM_COOKIE`，`workbuddy_*` 用 `WORKBUDDY_TOKEN`），只配一次。
- 脚本头部含 `cron:` 与 `new Env('...')`，订阅后自动创建任务；需调整执行时间时，改头部 cron 或面板里的定时规则。

## 订阅

公开仓库，拉取不需要 Token。

「订阅管理」→「新建订阅」，按下表填写：

| 字段     | 值                                                                                                |
| -------- | ------------------------------------------------------------------------------------------------- |
| 类型     | 公开仓库                                                                                          |
| 链接     | `https://github.com/Yutsuki92/qinglong-scripts.git`                                               |
| 分支     | `main`                                                                                            |
| 白名单   | 全部 `(_checkin\|_tasks)\.py$`<br />只签到 `_checkin\.py$`<br />只活动 `_tasks\.py$`               |
| 黑名单   | 留空                                                                                              |
| 依赖文件 | `ql_common\.py`                                                                                   |
| 定时规则 | `0 0 * * *`（每天同步仓库）                                                                       |

> **`ql_common.py` 要填在「依赖文件」里，不要放白名单。** 青龙会对白名单中每个 `.py` 尝试创建定时任务（解析不到 `cron:` 就用默认规则），公共库因此会被误建成一条任务；依赖文件只随脚本同步到目录、不单独建任务。

> 若任务列表里已经出现 `ql_common.py`，直接删除该任务即可，不影响其他脚本运行——它没有入口逻辑，万一被误跑也只是定义一批函数后退出（退出码 `0`）。

或直接执行（参数顺序：仓库地址、白名单、黑名单、依赖文件、分支）：

```bash
ql repo https://github.com/Yutsuki92/qinglong-scripts.git "(_checkin|_tasks)\.py$" "" "ql_common\.py" "main"  # 全部
ql repo https://github.com/Yutsuki92/qinglong-scripts.git "_checkin\.py$" "" "ql_common\.py" "main"           # 只签到
ql repo https://github.com/Yutsuki92/qinglong-scripts.git "_tasks\.py$" "" "ql_common\.py" "main"             # 只活动
```

若访问 GitHub 较慢，可在地址前添加 `https://gh-proxy.org/`（公开仓库不携带凭证，无泄露风险；加速服务稳定性无保证，失败可改直连）。

## 环境变量

「环境变量」→「新建」，「名称」和「值」都照下表填；多账号时值里每行一个。

| 脚本       | 变量                   | 格式                                                         | 示例（每行一个账号）                                                                                               |
| ---------- | ---------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| 阿里云盘   | `ALIYUN_REFRESH_TOKEN` | refresh_token                                                | `eyJhbGci…`<br />`eyJhbGci…`                                                                                       |
| 夸克网盘   | `QUARK_COOKIE`         | `user=任意; url=抽奖页;`<br />可省 url 只写 `kps/sign/vcode` | `user=张三; url=https://…&kps=abc&sign=def&vcode=111;`<br />`user=李四; url=https://…&kps=ghi&sign=jkl&vcode=222;` |
| 天翼云盘   | `TY_ACCOUNT`           | `账号:密码`<br />可单行 `a:p&&b:p`                           | `13800000000:密码`<br />`13900000000:密码含:冒号`                                                                  |
| 恩山论坛   | `ENSHAN_COOKIE`        | 浏览器登录后的整段 Cookie<br />须含 auth / saltkey（前缀不限） | `cdb_sid=AbCd; cdb_auth=1234; saltkey=abcd`<br />`rHEX_2132_auth=…; rHEX_2132_saltkey=…`           |
| 什么值得买 | `SMZDM_COOKIE`         | 整条 Cookie，要 `sess`                                       | `sess=abc123; user=zhangsan`<br />`sess=ghi789; user=lisi`                                                         |
| WorkBuddy  | `WORKBUDDY_TOKEN`      | `uid:Token`<br />`uid:` 可省                                 | `zhangsan:eyJ…`<br />`lisi:eyJ…`                                                                                   |
| 网易云音乐 | `NETEASE_COOKIE`       | `MUSIC_U` + `__csrf`<br />`#` 注释                           | `MUSIC_U=00a1…; __csrf=8f3a…`<br />`MUSIC_U=11d4…; __csrf=0a1b…`                                                   |

> 面板会把**同名多行**变量用 `&` 拼成一条再交给脚本（v2.23 实测），各脚本都能按「每行一个」正确拆开，不必手动拼接——夸克网盘、天翼按自身 cookie 结构切分，不会被 cookie 里的 `&` 误拆。

## 公共变量

这两个变量所有脚本通用，只需在面板配一次：

| 变量               | 默认值 | 说明                                                        |
| ------------------ | ------ | ----------------------------------------------------------- |
| `RANDOM_SIGNIN`    | `true` | 延迟开关。`false` 关闭全部等待（启动、账号间、模块/任务间） |
| `MAX_RANDOM_DELAY` | `300`  | 启动随机延迟上限（秒），用于错开请求高峰；设 `0` 只关启动延迟，账号间延迟不受影响 |

建议保持默认值。调试时可将 `RANDOM_SIGNIN` 设为 `false` 以跳过等待，但多账号会连续发送请求，存在触发风控的风险。默认账号间延迟为 10~20 秒。

两者分工：`RANDOM_SIGNIN` 是总开关，`MAX_RANDOM_DELAY` 只管启动延迟——设 `0` 只跳过启动，全停才用前者。

## 依赖

「依赖管理」→ 新建，类型选 Python，粘贴以下清单：

```text
requests
urllib3
rsa
pycryptodome
```

缺依赖时脚本不会直接抛 traceback 退出，而会打印缺哪个包、要粘哪份清单，并以退出码 `2` 结束（见下）。

## 退出码

青龙按退出码判断任务成败，本仓库统一为三档：

| 退出码 | 含义          | 典型场景                                     |
| ------ | ------------- | -------------------------------------------- |
| `0`    | 成功          | 全部账号签到成功，或均为「今日已签」         |
| `1`    | 运行失败      | 凭据失效、接口报错、部分或全部账号失败       |
| `2`    | 配置/依赖问题 | 环境变量缺失或为空、格式错误、缺 Python 依赖 |

`2` 与 `1` 分开，是为了在面板上一眼区分「要改配置」还是「要查接口」。

## 通知

通知优先走面板「通知设置」的渠道，其次 `notify.py`，再回落 `sendNotify.js`，都不可用只写日志——推送失败不影响签到。

每次只发一条汇总，标题三态（`成功｜x/y` / `部分失败｜成功 x/y` / `失败｜…`）：

```text
阿里云盘签到部分失败｜成功 1/2
📊 共 2 个账号｜✅ 成功 1｜❌ 失败 1
⏱️ 耗时 3 分 12 秒
🕐 完成于 2026-10-20 00:03:15

——— 账号明细 ———
✅ 账号1
👤 账号: 138****0000
📝 签到: 签到成功

❌ 账号2
❌ Token 已失效，请重新获取

——— 凭证与提示 ———
🔑 refresh_token 每次刷新都会轮换，脚本会尽量自动写回环境变量
```

配置/依赖类失败只发结论、不刷账号明细，标题如 `网易云音乐签到失败｜缺少依赖`；若通知仍是旧格式，删掉 `deps` 下的 `notify.py`、`sendNotify.js` 后重新更新订阅。

## 注意

- 宠物探险单次运行可能持续 1~4 小时，任务超时时间要调大、cron 间隔要留够，避免两次运行叠加。
- 凭据仅通过青龙环境变量传入，源码不含账号凭据，**请勿将 Cookie / Token 提交至仓库**。
